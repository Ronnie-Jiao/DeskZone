# Backend v0.1 手工验收

当前执行环境没有 .NET 10 SDK，因此本次已做 SQLite Schema 语法校验；以下项目需要在 Windows + .NET 10 环境完成首次编译运行验收。

## 启动与数据库

- [ ] 首次启动自动创建 `%LOCALAPPDATA%\DeskZone\deskzone.db`。
- [ ] `schema_migrations` 包含 `001_initial_local_backend`。
- [ ] 重启不会重复执行 v1 migration。
- [ ] 数据库 `PRAGMA quick_check` 返回 `ok`。

## 分类

- [ ] 创建 20 个分类，顺序正确。
- [ ] 重命名后重启仍保留。
- [ ] 折叠状态保存。
- [ ] 排序一次只产生一次事务写入。
- [ ] 非空分类使用默认删除策略时被拒绝。
- [ ] 非空分类内容可迁移到其他分类。
- [ ] 迁移到“未分类”不会删除真实文件。

## 文件引用

- [ ] 拖入文件只写引用，不移动真实文件。
- [ ] 拖入文件夹可识别为 Folder。
- [ ] `.lnk` 可识别为 Shortcut。
- [ ] 同一文件拖到另一个分类时改变归属，不复制入口。
- [ ] 从分类移除引用不删除真实文件。
- [ ] 外部删除文件后刷新状态标记为 missing，应用不崩溃。

## 布局

- [ ] Monitor / DPI / DIP / Size / Opacity / Collapsed / Locked 均可保存恢复。
- [ ] 透明度和最小尺寸的非法值被 Core 拒绝。

## 备份

- [ ] 手工备份可生成 SQLite 一致性副本。
- [ ] `settings.json` 存在时一并备份。
- [ ] 超过 8 份备份后自动清理最旧版本。
- [ ] 备份失败不会触发真实文件删除。

## 隐私

- [ ] 断网时上述功能均正常。
- [ ] 无用户账号、云数据库、遥测上传代码路径。

- 关键排查经验：DeskZone 的 Debug 预览实例会锁定 `src\DeskZone.App\bin\Debug\net10.0-windows\*.dll`，导致完整 `dotnet build DeskZone.sln` 报 MSB3027/MSB3021。两种处理方式：
  1. 不动运行实例，用独立输出目录验证编译：`dotnet build src/DeskZone.App/DeskZone.App.csproj -c Debug --no-restore -p:OutputPath=obj/verifybuild/`（事后删除各项目的 `obj/verifybuild`）。
